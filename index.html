Эта политика конфиденциальности описывает, как мы собираем, используем и защищаем ваши данные при использовании приложения "Радар кэфа такси" (далее - "Приложение").

1. ДАННЫЕ, КОТОРЫЕ МЫ СОБИРАЕМ

1.1 ДАННЫЕ О МЕСТОПОЛОЖЕНИИ

⚠️ ВАЖНО: Мы собираем ТОЧНЫЕ GPS-КООРДИНАТЫ вашего устройства для предоставления основной функции приложения - отображения актуальных цен такси на вашем текущем местоположении.

КАК МЫ ИСПОЛЬЗУЕМ МЕСТОПОЛОЖЕНИЕ:

  • Запрос актуальных цен такси через API Яндекс.Такси
  • Автоматическое обновление цен в виджете при вашем перемещении
  • Отображение вашей позиции на карте в приложении

ДОСТУП В ФОНОВОМ РЕЖИМЕ:

Приложение получает доступ к вашему местоположению когда работает в фоновом режиме (когда вы используете другие приложения). Это необходимо для работы виджета-оверлея, который отображает цены поверх других приложений.

Виджет работает как Foreground Service с постоянным видимым уведомлением в шторке, поэтому вы всегда знаете когда приложение использует ваше местоположение.

ЧАСТОТА СБОРА: Данные о местоположении запрашиваются каждые 10-15 секунд когда виджет активен.

ТИПЫ СОБИРАЕМЫХ ДАННЫХ О МЕСТОПОЛОЖЕНИИ:

  • Точное местоположение - GPS координаты (для точного расчета цен)
  • Приблизительное местоположение - Используется как резервный вариант

1.2 ИДЕНТИФИКАТОРЫ УСТРОЙСТВА

Мы собираем следующие идентификаторы:

  • Device ID (Android ID) - для управления подпиской и предотвращения злоупотреблений
  • Firebase Instance ID - для аналитики (автоматически через Firebase)
  • Advertising ID (AAID) - для показа релевантной рекламы (Yandex Mobile Ads)
  • AppMetrica Device ID - для аналитики (Yandex AppMetrica)

ЦЕЛЬ ИСПОЛЬЗОВАНИЯ:

  • Проверка статуса подписки (PRO/Free)
  • Предотвращение злоупотребления trial периодом
  • Аналитика использования приложения
  • Показ релевантной рекламы

1.3 ДИАГНОСТИЧЕСКИЕ ДАННЫЕ

Мы автоматически собираем:

  • Логи сбоев и ошибок (через Firebase Crashlytics)
  • Данные о производительности приложения
  • Информация об устройстве (модель, версия Android, язык)
  • Данные о действиях в приложении (клики, открытые экраны)

ЦЕЛЬ: Улучшение стабильности и производительности приложения.

2. ПЕРЕДАЧА ДАННЫХ ТРЕТЬИМ ЛИЦАМ

МЫ НЕ ПРОДАЕМ ВАШИ ДАННЫЕ ТРЕТЬИМ ЛИЦАМ.

Мы передаем ваши данные следующим третьим лицам:

2.1 GOOGLE FIREBASE

Передаются: Местоположение, Device ID, данные о производительности, логи сбоев

Цель: Аналитика, мониторинг сбоев, улучшение приложения

Политика: firebase.google.com/support/privacy

Конкретные сервисы:

  • Firebase Analytics - анализ использования приложения
  • Firebase Crashlytics - мониторинг ошибок и сбоев

2.2 YANDEX APPMETRICA

Передаются: Местоположение, Device ID, данные о действиях

Цель: Аналитика использования приложения

Политика: yandex.ru/legal/confidential

2.3 YANDEX MOBILE ADS

Передаются: Advertising ID, общая информация об устройстве

Цель: Показ релевантной рекламы

Политика: yandex.ru/legal/mobileads_sdk_agreement

2.4 НАШ СЕРВЕР

Передаются: Местоположение (для запросов цен такси), Device ID (для проверки подписки)

Цель: Получение актуальных цен такси, управление подпиской

3. КАК МЫ ЗАЩИЩАЕМ ВАШИ ДАННЫЕ

✅ Все данные передаются через защищенное HTTPS соединение

  • Device ID используется только для технических целей
  • Данные о местоположении не связываются с вашей личностью
  • Мы не собираем имена, email, номера телефонов или другую личную информацию
  • Ограничение доступа к данным - только уполномоченный персонал
  • Регулярное обновление систем безопасности

4. ВАШИ ПРАВА

4.1 ОТКЛЮЧЕНИЕ СБОРА ДАННЫХ

МЕСТОПОЛОЖЕНИЕ:

  • Вы можете отозвать разрешение на доступ к местоположению в настройках Android
  • ⚠️ Однако это сделает приложение непригодным для использования, так как без местоположения невозможно получить цены такси

АНАЛИТИКА:

  • Отключение аналитики технически возможно, но не предусмотрено в настройках приложения

РЕКЛАМА:

  • Вы можете ограничить отслеживание рекламы в настройках Android:
  • Настройки → Google → Реклама → Отключить персонализацию рекламы

4.2 УДАЛЕНИЕ ДАННЫХ

Вы можете запросить удаление всех собранных о вас данных.

КАК ЗАПРОСИТЬ:

Отправьте письмо на rvdtgme@gmail.com с темой "Удаление данных" и укажите:

  • Device ID (можно найти в настройках приложения)
  • Описание запроса

СРОК: Мы удалим все ваши данные в течение 30 дней.

ЧТО БУДЕТ УДАЛЕНО:

  • Device ID с нашего сервера
  • История запросов местоположения
  • Аналитические данные (где это технически возможно)
